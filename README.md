# 机器臂实验计划1

小黄黄的网页版 3D 机械臂交互演示。React、TypeScript、Three.js、Vite；无需后端、账号、密钥或外部模型请求。

## 开发

Node.js 22.12+（当前已验证 Node.js 24）。在本仓库运行：

```sh
npm ci
npm run dev -- --port 5173
```

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

浏览器测试默认使用 `/usr/bin/chromium`。其他环境通过 `CHROMIUM_PATH` 指定 Chromium 的完整可执行路径。测试包含键盘和指针、停止条件、错误重试、响应式布局及 axe 可访问性检查。`npm run format:check` 检查格式。

## 操作

- W / S：世界 Z 轴正 / 负方向。
- A / D：世界 X 轴负 / 正方向；与当前相机视角无关。
- 默认“大臂肘部”：控制第一段大臂末端，即 J3 原点。大臂长度固定，目标投影至肘部可达弧线，X/Z 会联动；这是弧线上的方向控制，不能自由平移。
- “末端执行器”：位置逆运动学，移动法兰，固定 Y，末端朝向自由。组合键归一化，不会加速。
- 方向键可按住触控；Enter / Space 也可操作屏幕方向按钮。
- 松键、窗口失焦、页面隐藏、输入控件焦点、打开指南、暂停、切换模式时停止。
- 鼠标左键旋转、右键平移、滚轮缩放；等效按钮提供旋转、缩放、透视/正视/俯视和重置视角。

## 模型、许可证和约束

真实模型取自 [ros-industrial/fanuc](https://github.com/ros-industrial/fanuc/tree/d8f42bd73584b255df87098395512538882caea1/fanuc_r1000ia_support)，固定版本 `d8f42bd73584b255df87098395512538882caea1`。

原始视觉 STL（7 个文件，未修改）、展开后的 URDF 和 BSD 3-Clause 许可证位于 `public/models/fanuc-r1000ia80f/`。Xacro 展开移除了 collision 描述和宏，保留串联结构、网格坐标、关节原点、轴、角度及速度限位；材料颜色略作显示调整。原始版权归 TU Delft Robotics Institute 及贡献者所有。FANUC 名称和模型标识不代表制造商背书。

纯 Three.js 场景图从 URDF 构建。肘部使用刚性上臂的圆弧解析投影；末端使用带阻尼的雅可比最小二乘求解。每帧目标从已接受姿态出发，遵守关节角度和速度限位，不保留不可达目标。长帧按不超过 25ms 的子步追赶（最多 500ms），避免切回页面时跳跃。默认参数保存在 `src/robot.ts`，设计说明见 `DESIGN.md`。

仅用于交互演示。不包含动力学、实体控制、逆运动学朝向约束、自碰撞或环境碰撞检测。模型自身的制造商机械耦合约束未额外建模，不能用于工业运动规划。末端模式在奇异位形、关节边界或工具接近地面时拒绝该步运动并提示边界。肘部模式的投影位移速度可能低于设置的笛卡尔指令速度。

## 云环境

此任务已位于隔离的现有 checkout，无需另建 Git worktree。安装依赖后启动 Vite；运行中的服务不会随环境快照恢复，需要重新启动。模型随仓库本地提供，启动后无需外部网络连接。`.npmrc` 把安装缓存放在允许写入的 `/tmp`。
